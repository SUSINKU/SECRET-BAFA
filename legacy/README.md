# Prototype d'origine

Le premier jet de Secret BAFA : quatre pages statiques qui stockaient tout dans le
`localStorage` du navigateur. Conservé pour mémoire — chaque téléphone y avait ses propres
données, il n'y avait donc pas de partie commune possible.

L'application actuelle vit à la racine du dépôt (`server/` et `public/`). Le logo a été
déplacé vers `public/images/`, les images de ces pages ne s'affichent donc plus.
